# Mesh Projector

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python Version](https://img.shields.io/badge/python-3.12.9-blue.svg)](https://www.python.org/)
[![Rust Version](https://img.shields.io/badge/rust-2021-orange.svg)](https://www.rust-lang.org/)

A Rust-based Python library for generating 2D projections and point clouds from 3D mesh files.

## Core Features

*   **Mesh Loading:** Loads `.obj` files, automatically inferring the rendering mode from the provided files:
    *   **OBJ only:** The renderer will not use any textures, only the geometry and triangle colors (if present).
    *   **OBJ + Texture:** The renderer will use the texture, but no shading is applied.
    *   **OBJ + Texture + MTL:** The renderer will use the texture and mtl file, and apply the shading based on the mtl file
*   **Bounding Cube Projection:** Generate 6 orthographic projections onto the faces of the mesh's bounding cube.
*   **Rotation-Based Projection:** Create a sequence of projections by incrementally rotating the mesh.
*   **Point Cloud Generation:** Sample the mesh surface to create a dense point cloud.
*   **Rich Output:** Projections yield RGB images, depth maps, normal maps, and occlusion maps as NumPy arrays.
*   **Configuration:** Control output resolution, apply outlier filtering, and adjust point cloud density.

## Installation

### Prerequisites

1.  **Rust Toolchain:** Install from [rustup.rs](https://rustup.rs/).
2.  **Conda (Recommended):** For managing Python environments. Install [Miniconda](https://docs.conda.io/en/latest/miniconda.html).
3.  **Python:** Version 3.12.9 is specified.

### Steps

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/arthurhscarvalho/mesh-projector
    cd mesh-projector
    ```

2.  **Create and activate the Conda environment:**
    ```bash
    conda env create -f environment.yml
    conda activate mesh_projector
    ```

3.  **Build and install the package:**
    ```bash
    maturin develop -r
    ```

## Usage

The primary workflow involves loading a mesh and then using one of the projection or sampling functions.
Full usage examples are provided in the [examples](examples/) folder.

```python
import cv2
import mesh_projector as mp
import os

# 1. Load a mesh from an OBJ file
mesh = mp.read_mesh(
    obj_path="assets/just_a_girl_C0-L5_deq_tri.obj",
    texture_path="assets/just_a_girl_C0-L5_deq_tri_0.png",
    mtl_path="assets/just_a_girl_C0-L5_deq_tri.mtl",
    precision=12,  # Results in 4096x4096 output images
    verbose=True,
)

# 2. Generate 6 projections onto the bounding cube
projections, depth_maps, normal_maps, occupancy_maps = \
    mp.project_to_image_on_bounding_cube(mesh, filtering=0)

# 3. Save the first projection image
os.makedirs("output", exist_ok=True)
cv2.imwrite(
    "output/projection_0.png",
    cv2.cvtColor(projections[0], cv2.COLOR_RGB2BGR)
)
```

### Key Functions

*   `read_mesh(obj_path, texture_path, mtl_path, ...)`: Loads a mesh and prepares it for processing. The rendering mode is inferred from the provided files.
*   `project_to_image_on_bounding_cube(mesh, ...)`: Returns 6 projections (color, depth, normal, occlusion) from the faces of the bounding cube.
*   `project_to_image_by_rotation(mesh, ...)`: Returns a series of projections generated by rotating the mesh.
*   `project_to_point_cloud_by_sampling(mesh, ...)`: Returns a point cloud with point coordinates and colors.
